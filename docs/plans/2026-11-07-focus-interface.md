# 聊天界面与侧栏分组

- 日期：2026-11-07
- 本地用户确认：以所提供的 Grok Bot 截图为布局参考。先前的平铺「专注版」不符合要求，本决定替代它。

## 外观

- 浅灰侧栏保留主 Bot 卡片；普通 Bot 使用彩色原创头像、名称、单行消息预览。搜索、新建保持圆形按钮。
- 顶部恢复居中的浮动 Bot 胶囊；点击打开资料，群目标、记忆通知和工作状态继续可用。
- 默认使用四角圆润的浅灰 Bot 回复气泡和靠右的深色用户气泡，回复正文增加内边距。显式选择的平铺模式仍保留。
- 私聊右侧气泡和语音按钮共用底色，配白字和白色图标。底色取当前 Bot 的头像色，对比度低于 4.5:1 时压深。
- 带引用的用户气泡用左侧细线标出引用，回复另起一行。长引用收在预览宽度内。
- 底部恢复单行圆角输入框，附件在左、语音和发送在右；长消息和附件可以自然展开。
- 深色主题、桌面标题栏安全间距、窄侧栏、抽屉和详情面板继续适配。
- 使用 DS Bot 原创头像和现有图标，不复制第三方素材，不添加不存在的分享功能。

## 侧栏分组

- Bot 和群聊的右键菜单增加「移至分组」，可移入已有分组、输入名称创建分组，或移回「未分组」。名称最多 48 个字符。
- 分组按名称排序，未分组排在最后；内部保持置顶和最近活动排序。空分组自动消失，主 Bot 保留独立卡片。
- 点击分组标题折叠或展开，显示可见会话数；窄栏直接展示头像，不隐藏折叠组里的会话。
- 顶部按钮与主 Bot 卡片固定在滚动列表之外；分组折叠、展开或出现滚动条时，侧栏宽度和这两个区域的位置保持不变。
- 分组名称存入对应会话的 category 字段，随团队保存；展开状态仅为当前设备偏好，按团队和分组保存在浏览器存储。
- 分类是用户侧栏整理方式，不改变群聊成员、Bot 权限或任务路由。
